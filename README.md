# Fraudulent_Job_detection_Project

## Overview
This project focuses on analyzing fraudulent job postings using Python (Colab Notebook) and visualizing insights through an interactive Power BI dashboard. The aim is to identify patterns and indicators that help distinguish fake job listings from genuine ones.

## Objective
The goal of this project is 

1. Detect and analyze fraudulent job postings
2. Identify key features that indicate job scams
3. Perform data cleaning and exploratory analysis
4. Build a dashboard to visualize insights clearly

## Tools & Technologies
1. Python (Pandas, NumPy)
2. Colab Notebook
3. Power BI
4. Power Query
5. DAX

## Project Workflow

**Data Cleaning & Preparation (Python)**
1. Handled missing values
2. Removed duplicates
3. Standardized job-related fields

**Exploratory Data Analysis (EDA)**
1. Compared fraudulent vs genuine job postings
2. Analyzed features like salary, location, and job type
3. Identified suspicious patterns

**Visualization & Dashboard (Power BI)**
1. Built interactive dashboard
2. Added filters for job type, location, and fraud status
3. Created KPIs to track fraud distribution

## Key Features
1. End-to-end data analysis project
2. Fraud detection insights
3. Interactive Power BI dashboard
4. Clear and structured visualizations

## Key Insights
1. Certain job categories have higher fraud rates
2. Missing or vague descriptions often indicate fraud
3. Unrealistic salary ranges are a common red flag
4. Some locations show higher concentration of fake postings
